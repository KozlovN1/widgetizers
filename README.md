# widgetizers
Implement matplotlib.widgets with ease

- pip3 install -r requirements.txt

Available functions:

    - make_axis_checkable(ax, lst=None, coords=None)
    - make_figure_checkable(fig, axs=None, lst=None, coords=None)
    - make_axis_pickable(ax, lst=None, radius=1)
    - add_axis_selector(ax, base, signal, func)

- from widgetizers.widgetizers import (

    make_axis_checkable, make_figure_checkable,
    make_axis_pickable, add_axis_selector

  )

[PyPi](https://pypi.org/project/widgetizers/)
